- 后端 `bls-ai-service/src/api/chat/index.ts` 输出 OpenAI 兼容 SSE：`data: {"choices":[{"delta":{"content":"..."}}]}` + `data: [DONE]`。

  - 支持 `json.error?.message` 错误透传（throw 非 Error 则忽略）

- 已确认 `chat-provider.ts` 的 `chatStream()` 也已支持 `json.choices?.[0]?.delta?.content`（兼容双格式 `|| json.content`）。
