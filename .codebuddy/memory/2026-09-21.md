# 2026-09-21

## 登录两级人机验证（captcha）— Koa 后端 + 登录页 + 系统参数页

需求：在认证安全闭环中新增「静默行为验证 → 滑块/旋转可视化验证 → 一次性 captchaToken → 登录消费」。

### 后端（bls-server）

- 新增模块 `src/security/captcha/`：
  `types.ts` / `crypto-utils.ts`（crypto.randomBytes+randomInt、timingSafeEqual、HMAC 签名 Token）/
  `config.ts` / `store.ts`（Redis，全部带 TTL，无 Lua：`SET NX EX` + `GETDEL` 做一次性消费）/
  `silent.ts`（白名单化 interactionSummary + 评分 + PoW）/ `policy.ts`（强制二级策略 + 风险提供者）/
  `image.ts`（后端生成 SVG：滑块拼图 + 图像旋转）/ `service.ts`（编排）/ `createChallenge|verifySilent|verifySecondary|consumeLoginToken`。
- 新增公共路由 `src/api/auth/captcha/index.ts`（`new Router({prefix:'/auth/captcha'})`）：
  `GET /config`、`POST /challenge`、`POST /silent/verify`、`POST /secondary/verify`、`GET /image/:id`，全部 `no-store`。
- `src/core/router.ts`：**扫描器现在始终递归子目录**（原来父目录有 index.ts 就跳过），
  这样 `api/auth/index.ts`（函数路由）与 `api/auth/captcha/index.ts`（自定义 Router）可以共存。
- `src/config/dynamic-config.ts`：SCHEMA 新增 `enum` / `csv` 两种类型（含范围与枚举校验，非法值回退默认并告警），
  新增 9 个 `sys.login.captcha.*` 参数；`toPublicCaptchaConfig()` 只投影 `{enabled,mode,secondaryTypes}`。
- `src/core/errors.ts`：40010 CAPTCHA_REQUIRED / 40011 INVALID / 40012 EXPIRED / 40013 REPLAYED / 50301 SERVICE_UNAVAILABLE。
- `src/api/auth/index.ts`：登录前先 `consumeLoginToken`（一次性 token，绑定 challenge/租户域名/username/IP/UA hash）；
  captcha 错误不计入登录失败、不发 LOGIN_FAILED；成功 → `resetLoginFailures`，失败 → `recordLoginFailure`。
- `src/security/rate-limit/`：新增 `device` 维度；`account` 维度在 body 无 username 时回退为 `ip:{hash}`（避免匿名共享桶）；
  新增 9 条 captcha 限流规则。
- `core/security-audit.ts` 新增 8 个 `CAPTCHA_*` 事件；`event-center/risk-rules.ts` 新增 `rule_captcha_token_abuse`。
- `app.ts` / `env.ts`：生产环境 `CAPTCHA_SECRET` 必填 ≥32 位；`CAPTCHA_DEV_BYPASS=true` 生产环境阻止启动。
- 数据：`sql/Init.sql` 增 `000406`–`000414`（用 Node 脚本写，IDE 编辑 sql/Init.sql 会静默丢失）；
  迁移 `bls-server/migrations/20260922_017_login_captcha.sql`（只 seed，无 DDL —— event_type 是 varchar(64)）。
  注意：**编号 015/016 已被并发会话占用**（password_reset_token / api_key），所以用 017。
- 测试：`src/security/captcha/__tests__/`（silent / captcha-service / captcha-audit / image / fake-redis），
  覆盖需求第九节 19 项；全套 623 项通过。

### 前端（bls-admin）

- `src/services/auth/captcha.ts`（4 个接口，全部 `skipErrorMessage`）。
- `src/auth/behavior-collector.ts`：只累积**统计量**（计数、间隔均值/σ、速度、blur/visibility、navigator.webdriver），

  直接读写这 9 个 `sys_config` 参数并在保存后提示「立即生效」。
